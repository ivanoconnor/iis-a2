# Daybreak design guidelines

- Use Material Design 3 proportions with warm ivory surfaces, dark brown text, terracotta actions, and soft sage selection. No gradients.
- Use large light-weight time numerals, rounded cards, pill buttons, thin borders, and an 8px spacing rhythm. Use a system sans-serif and tabular numerals.
- Keep each screen focused: one heading and functional content. Avoid extra subtitles, status indicators, and decoration.
- Use a left navigation rail on desktop and a bottom bar on mobile. Stack cards and preserve touch targets on small screens.
- Use explicit form labels, readable contrast, visible keyboard focus, and native time controls.
- Persist settings locally. Apply preferences immediately; save or cancel manual alarm changes explicitly. Use 24-hour time.
- A night belongs to the day it begins; its alarm follows the next morning's schedule. Manual overrides take precedence and expire after their alarm time.
